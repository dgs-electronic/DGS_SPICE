feat: Remove command-line analysis flags; determine analysis from netlist control statements

- Removed -OP, -TRAN, and -AC command-line flags from DGS_SPICE.
- Added parser support for `.op` and `.ac` control cards in the netlist.
- Analysis mode is now determined entirely by the control statements in the netlist (`.op`, `.tran`, or `.ac`), defaulting to DC OP if none are present.
- Unsupported/unimplemented `.ac` card correctly throws an error and exits with code 3.
- Rebuilt with Free Pascal `lazbuild`.
- Updated documentation (README.md, docs/documentation.md) and message.txt to match this design change.
